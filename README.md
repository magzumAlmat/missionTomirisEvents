# EventTomiris — Городской квест на QR-кодах 🏆

Интерактивная веб-система для проведения городского квеста. Участники регистрируются, сканируют засекреченные QR-коды на локациях, получают загадки, отправляют уведомления в Telegram организаторам, зарабатывают буквы и находят финальный приз.

---

## 🚀 Быстрый запуск на сервере / локально

### Запуск одной командой (Рекомендуется):
```bash
./start.sh
# или
npm run deploy
```

Скрипт автоматически:
1. Проверит и подтянет конфигурацию `.env`.
2. Установит все зависимости (`npm install`).
3. Сгенерирует защищённые QR-коды для всех точек в `qr-output/`.
4. Соберёт оптимизированный продакшн-фронтенд (`npm run build`).
5. Освободит порт и запустит бэкенд с Telegram-ботом.

## 🗺️ Страницы сайта (Маршруты)

| URL | Экран | Описание |
|---|---|---|
| `/#/` | **Главная (Start)** | Афиша квеста, правила, ввод команды/телефона, переход к старту. |
| `/#/landing` | **Продающий Лендинг** | Промо-страница с живым обратным отсчётом до старта, карточками фишек, FAQ и кнопками бронирования. *(также `/#/welcome`)* |
| `/#/register` | **Форма регистрации** | Регистрация участников: Имя, Телефон, Наличие авто (Да/Нет). *(также `/#/reg`)* |
| `/#/s/:code` | **Точка квеста (Station)** | Задание точки по секретному коду (напр. `/#/s/x9f2a8`), кнопки «📍 Я прибыл» и «🧩 Я отгадал». |
| `/#/progress` | **Мой прогресс** | Собранные буквы, список пройденных точек, кнопка сброса прогресса для тестов. |
| `/#/final` | **Финал** | Экран ввода итогового слова (кода) и получение приза. |
| `/#/admin` | **Панель админа** | Генерация и печать QR-кодов в браузере (пароль из `VITE_ADMIN_PASSWORD`). |

## 🤖 Команды Telegram-бота в группе

Бот отправляет все события в Telegram-группу организаторов (`TELEGRAM_CHAT_ID`).

В чате группы доступны команды и интерактивные кнопки:

* **`/list`** (или `/список`, `/participants`) — вывести список всех зарегистрированных участников с номерами телефонов, наличием машины и датой регистрации.
* **`/finish_quest`** (или `/finish`) — завершить квест и очистить список участников для нового запуска.
* **Интерактивные кнопки:** под каждым уведомлением доступны кнопки `[ 📋 Показать список ]` и `[ 🔄 Обновить список ]`.

## 🔲 Защита QR-кодов от подбора URL

Все точки используют **непредсказуемые секретные коды (хеш-токены)** вместо порядковых номеров:
* Точка 1: `/#/s/x9f2a8`
* Точка 2: `/#/s/v4k8n1`
* Точка 3: `/#/s/b2r9p5`
* ...

Участники не могут угадать URL следующих точек в адресной строке — точку можно открыть только отсканировав реальный QR-код на локации.

## ⚙️ Настройка файла `.env`

Создайте `.env` в корне проекта (или используйте созданный автоматически):

```env
# --- Telegram (бэкенд) ---
TELEGRAM_BOT_TOKEN=ваш_токен_из_BotFather
TELEGRAM_CHAT_ID=-100XXXXXXXXXX   # ID группы (начинается с минуса)
ALLOWED_ORIGIN=*
PORT=3001

# --- Фронтенд (Vite) ---
VITE_API_URL=http://ваш-ip-или-домен:3001
VITE_ADMIN_PASSWORD=tomiris2026
```

> 💡 Чтобы узнавать `TELEGRAM_CHAT_ID` группы, добавьте бота в группу, напишите любое сообщение и откройте: `http://localhost:3001/api/chat-id-helper`

## ⚙️ Структура проекта

```

├─ start.sh                   # Единый авто-скрипт деплоя и запуска

├─ server/

│  └─ participants.json       # Хранилище зарегистрированных участников
├─ src/
│  ├─ questConfig.js          # 🌟 ВСЕ ЗАДАНИЯ И ТОЧКИ КВЕСТА
│  ├─ App.jsx                 # Маршрутизация (HashRouter)
│  ├─ styles.css              # Стили и темы
│  ├─ lib/                    # API, телефон, команда
│  └─ pages/                  # Landing, Register, Start, Station, Progress, Final, Admin
├─ scripts/generate-qr.js     # Скрипт массовой генерации QR-кодов
└─ qr-output/                 # Сгенерированные PNG и печатный лист index.html
```
