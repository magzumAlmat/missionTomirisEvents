# 📚 Панель администратора EventTomiris — раздел "Загадки"

## 🎯 Задача

Создать полноценную панель администратора с разделом «Загадки», который позволяет:
- Просматривать список загадок
- Добавлять/редактировать вопросы к загадкам
- Настраивать тайм-лимиты и подсказки
- Управлять категориями загадок

---

## 📁 Структура файлов

```
src/pages/admin/
├── AdminTab.jsx                    — главный компонент с табами (QR, капитаны, загадки)
├── EditRiddle.jsx                 — редактирование свойств загадки (заголовок, тайм-лимит)
├── ViewRiddle.jsx                 — просмотр загадки со списком вопросов
├── EditRiddleEditor.jsx           — редактор списка вопросов внутри загадки
├── AddQuestionForm.jsx            — добавление нового вопроса к загадке
├── EditQuestion.jsx               — редактирование отдельного вопроса
├── CategoriesList.jsx             — управление категориями загадок
├── RiddleSettings.jsx             — настройки тайм-лимита и подсказок
├── AdminStyles.css                — общие стили для админки
└── HANDOFF.md                     — подробный анализ работы всех кнопок
```

---

## 🧭 Навигация между разделами

### Верхние табы (главная панель)

| Таб | URL | Действие |
|-----|-----|----------|
| **📱 QR-коды** | `/admin/qr` | Главная страница генерации QR-кодов |
| **👑 Капитаны** | `/admin/captains` | Управление капитанами и участниками |
| **🙋 Участники** | `/admin/solo` | Одиночные (не зарегистрированные) пользователи |
| **🧩 Загадки** | `/admin/riddles/list` | Список загадок, добавление вопросов, категории |

## 🗂️ Раздел «Загадки» — структура

### Главная страница раздела: `/admin/riddles/list`

На этой странице можно:
- Просматривать список загадок
- Добавить новый вопрос к загадке (к существующей или новой)
- Перейти на страницу редактирования свойств загадки
- Открыть настройки тайм-лимита и подсказок
- Перейти в раздел категорий загадок

**Кнопки:**
| Кнопка | Действие | URL после нажатия |
|--------|----------|-------------------|
| 📋 Список загадок (активная) | Ничего — уже активна | — |
| + Добавить вопрос к новой загадке | Открывает форму добавления вопроса | `/admin/riddles/list` → форма добавления |
| 🖊️ Редактировать загадку (свойства) | Перенаправляет на редактирование свойств | `/admin/riddles/:id/edit-questions` |
| ⚙️ Настройки загадки | Открывает настройки тайм-лимита и подсказок | `/admin/riddles/:id/settings` |
| 🏷️ Категории загадок | Перенаправляет на страницу категорий | `/admin/riddles/categories` |
| ← Назад к списку | Закрывает форму, остаётся в режиме списка | — |

---

### Просмотр загадки: `/admin/riddles/:id/view`

На этой странице можно:
- Редактировать свойства загадки (заголовок, тайм-лимит)
- Добавить новый вопрос к загадке
- Открыть настройки тайм-лимита и подсказок
- Перейти в раздел категорий загадок

**Кнопки:**
| Кнопка | Действие | URL после нажатия |
|--------|----------|-------------------|
| 🖊️ Редактировать загадку (свойства) | Перенаправляет на редактирование свойств | `/admin/riddles/:id/edit-questions` |
| + Добавить вопрос к этой загадке | Открывает форму добавления вопроса | `/admin/riddles/:id/view/add-question` |
| ← Назад к списку загадок | Возвращает на страницу списка | — |
| ⚙️ Настройки загадки | Открывает настройки тайм-лимита и подсказок | `/admin/riddles/:id/settings` |
| 🏷️ Категории загадок | Перенаправляет на страницу категорий | `/admin/riddles/categories` |
| ← На страницу QR-кодов | Возвращает на главную страницу админки | `/admin/qr` |

---

### Редактирование свойств загадки: `/admin/riddles/:id/edit-questions`

На этой странице можно редактировать свойства загадки (заголовок, тайм-лимит).

**Кнопки:**
| Кнопка | Действие | URL после нажатия |
|--------|----------|-------------------|
| ← Назад к списку вопросов | Возвращает на страницу просмотра | `/admin/riddles/:id/view` |
| + Добавить вопрос | Открывает форму добавления нового вопроса | `/admin/riddles/:id/edit-questions/add-question` |

---

### Добавление вопроса: `/admin/riddles/:id/edit-questions/add-question`

На этой странице можно добавить новый вопрос к загадке.

**Кнопки:**
| Кнопка | Действие | URL после нажатия |
|--------|----------|-------------------|
| ← Назад к списку вопросов | Закрывает форму, остаётся в режиме списка | — |
| ✅ Сохранить вопрос | Записывает новый вопрос и возвращает в режим просмотра | `/admin/riddles/:id/view` |
| Отмена | Возвращает без сохранения | — |

---

### Редактирование отдельного вопроса: `/admin/riddles/:id/edit-questions/question/:questionId`

На этой странице можно редактировать текст вопроса и ответ.

**Кнопки:**
| Кнопка | Действие | URL после нажатия |
|--------|----------|-------------------|
| ← Назад к списку вопросов | Возвращает во вкладку списка вопросов | `/admin/riddles/:id/edit-questions` |
| ✅ Сохранить вопрос | Записывает изменения и возвращает в режим просмотра | `/admin/riddles/:id/view` |
| Отмена | Возвращает без сохранения | — |

---

### Настройки загадки: `/admin/riddles/:id/settings`

На этой странице можно настраивать тайм-лимит, показывать ли подсказки и т.д.

**Кнопки:**
| Кнопка | Действие | URL после нажатия |
|--------|----------|-------------------|
| ← Назад к списку вопросов | Возвращает во вкладку списка | `/admin/riddles/:id/view` |
| ✅ Сохранить настройки | Записывает изменения и возвращает в режим просмотра | `/admin/riddles/:id/view-settings` |
| Отмена | Возвращает без сохранения | — |

---

### Просмотр настроек загадки: `/admin/riddles/:id/view-settings`

На этой странице отображаются текущие настройки загадки.

**Кнопки:**
| Кнопка | Действие | URL после нажатия |
|--------|----------|-------------------|
| ⚙️ Редактировать настройки | Перенаправляет на страницу редактирования настроек | `/admin/riddles/:id/settings` |
| ← Назад к списку вопросов | Возвращает в режим просмотра списка | `/admin/riddles/:id/view` |

## 🧪 Проверка работы всех кнопок

Для проверки работоспособности всех кнопок выполните следующие шаги:

1. Откройте приложение по адресу `http://localhost:3000/admin/qr`.
2. Перейдите в раздел «Загадки» (URL: `/admin/riddles/list`).
3. Проверьте работу каждой кнопки:
   - Кнопка «Редактировать загадку» → должна перенаправить на страницу редактирования свойств.
   - Кнопка «Назад к списку» → должна вернуть в режим просмотра без потери данных.
   - Кнопка «Назад к предыдущей странице» → должна вернуться на `/admin/qr`.
   - Все кнопки навигации между подвкладками должны работать без перезагрузки страницы (React Router).

---

## 📝 Примечания

- Все переходы осуществляются через React Router, поэтому нет необходимости в перезагрузке страницы.
- Состояние форм сбрасывается при нажатии кнопок «Назад», чтобы избежать утечки данных между разделами.
- Для сохранения изменений вызывается API (в mock-режиме используется `setTimeout`).
